# SmartHire

SmartHire is a job marketplace platform for job seekers, recruiters, and administrators.

## Project Status

Initial repository setup. Application source files will be added in later commits.

## Planned Modules

- Authentication and user roles
- Recruiter job management
- Job seeker dashboard
- Admin dashboard

## Team Workflow

- `main` contains the shared stable branch.
- Each team member works on a separate feature branch.
- Changes are merged through pull requests.

## Security

Do not commit `.env`, `.env.local`, database credentials, or other secrets.
